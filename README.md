### Descrição
Realização de atividade crucial para consolidar os conhecimentos adquiridos durante a aula.

### Objetivo
Consolidar o conhecimento apresentado em aula, abordando os seguintes tópicos: 
- Criação de repositório
- Adição de arquivos
- Adição de branch
- Clone de repositório
